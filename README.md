# ENG-Dictionary 📚

**Консольный словарь английских слов на Python.**

Интерактивное меню в терминале: создавайте собственный словарь слов и словосочетаний с переводами, ищите их по первой букве, удаляйте ненужное и проверяйте себя в викторине. Без внешних библиотек, словарь хранится в обычном JSON-файле.

## Запуск

Склонируйте репозиторий и запустите программу. Устанавливать ничего не нужно, используется только стандартная библиотека:

```bash
git clone https://github.com/GDKopat/ENG-Dictionary.git
cd ENG-Dictionary
python main.py
```

При первом запуске выберите пункт `1`: программа создаст файл `dictionary.json` с двумя тестовыми записями. Остальные пункты меню работают только после его создания.

> [!NOTE]
> Файл `dictionary.json` создаётся в папке, из которой запущена программа, поэтому запускайте её всегда из одной и той же директории.

## Возможности

| Функция | Описание |
|---------|----------|
| **Показать словарь** | Создаёт `dictionary.json`, если его нет, или выводит всё содержимое словаря |
| **Добавить / изменить** | Добавляет слово или словосочетание с переводом; если такое уже есть, значение заменяется |
| **Поиск по первой букве** | Выводит все слова на введённую букву вместе с их значениями, регистр не важен |
| **Викторина** | Показывает слово и четыре варианта перевода, считает долю правильных ответов за сессию |
| **Удаление** | Показывает слова на выбранную букву и удаляет нужное после подтверждения `y / n` |
| **Защита от ошибок** | Проверяет наличие файла словаря и корректность ввода в меню, поиске и викторине |

## Пример работы

```
Привет! это словарь английских слов!
1 - Показать словарь
2 - Добавить/изменить   слово/словосочетание
3 - Найти слова/словосочетания по первой букве
4 - Викторина
5 - Удалить слово/словосочетание
0 - Выход
Введите действие:
```

Так выглядит вопрос викторины:

```
==================================================
1 попытка. Вопрос: Что означает слово/словосочетание 'bed'?
==================================================
1. стол
2. кровать
3. окно
4. дверь
--------------------------------------------------
Ваш ответ (номер варианта):
```

Формат файла `dictionary.json`:

```json
{
    "some test word": "some test text",
    "bed": "кровать"
}
```

## Известные ограничения

- Для викторины в словаре должно быть минимум 4 слова.
- Поиск по букве выполняется один раз за вызов: после показа результата программа возвращается в главное меню.
- Для удаления слова сначала нужно найти его через поиск по первой букве.
- Слова считаются разными, если отличаются регистром: `Bed` и `bed` будут двумя записями.
- Статистика викторины не сохраняется между запусками.
